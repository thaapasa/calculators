# Links

A list of links the user wants to keep at hand. The list is stored in the browser.

## Links

- [x] User can type a link and open it from the preview below the input.
- [x] If the link has no scheme, the page adds `http://`.
- [x] User can add the link to the stored list. Adding a link that is already in the list
      does nothing.
- [x] User can open a stored link. Links open in a new tab.
- [x] User can remove a stored link.
- [x] The list is stored in the browser and restored when the user comes back.
